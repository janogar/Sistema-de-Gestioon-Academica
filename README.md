# Sistema de Gestión Académica

## Descripción

Este proyecto consiste en el desarrollo de una API REST para la gestión de un sistema académico. Su objetivo es facilitar la administración de estudiantes, cursos e inscripciones, permitiendo gestionar la información mediante solicitudes HTTP.

La aplicación está desarrollada utilizando **Java y Spring Boot**, con **Spring Data JPA** para la interacción con la base de datos y **PostgreSQL** como sistema de almacenamiento.

## Funcionalidades principales

- Gestión de estudiantes.
- Gestión de cursos.
- Gestión de inscripciones.
- Operaciones de consulta y administración mediante endpoints REST.
- Persistencia de datos mediante JPA y PostgreSQL.

## Tecnologías utilizadas

- Java 17
- Spring Boot
- Spring Data JPA
- Hibernate
- PostgreSQL
- Maven
- API REST

## Endpoints principales

| Recurso | Endpoint |
|---|---|
| Estudiantes | `/estudiantes` |
| Cursos | `/cursos` |
| Inscripciones | `/inscripciones` |

## Objetivo del proyecto

Este proyecto fue desarrollado con fines de aprendizaje y práctica, aplicando conceptos de programación orientada a objetos, arquitectura en capas, desarrollo de servicios REST, persistencia de datos y conexión con bases de datos relacionales.
